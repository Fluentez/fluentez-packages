@fluentez/ui Skeleton Screen Generator

Zero-dependency, 100% geometry-matching skeleton placeholder generator for Vanilla JS & React applications.

Live Interactive Demo

Fluentez UI skeleton generator reads computed styles and layout dimensions dynamically from real DOM elements to construct seamless placeholder overlays.

Installation

$ bun add @fluentez/ui

Function Signature

function createSkeleton(
  target: HTMLElement | string,
  options?: SkeletonOptions
): SkeletonController;

// Alias
const skeletonize = createSkeleton;

Configuration Options (SkeletonOptions)

Every aspect of skeleton generation can be customized via the options parameter object:

Option Type Default Allowed Values & Description
animation AnimationType 'shimmer' 'shimmer' | 'pulse' | 'wave' | 'none'.
Controls the animation effect applied to generated skeleton blocks.
theme ThemeMode 'auto' 'auto' | 'light' | 'dark' | { skeleton?, highlight?, background? }.
Color mode or custom object: skeleton (or background) sets base block color, highlight sets shimmer light streak color.
borderRadius string | number | 'auto' 'auto' 'auto' (reads computed style) | numeric pixels (e.g. 8) | CSS string (e.g. '50%').
exclude string | ((el: HTMLElement) => boolean) undefined CSS query selector string (e.g. '.skip-me') or predicate function. Matched elements are ignored completely.
keep string | ((el: HTMLElement) => boolean) undefined CSS query selector string or predicate function. Matched elements remain visible as-is inside the overlay.
fadeDuration number 250 Duration in milliseconds for fading out skeleton when calling restore().
className string '' Custom CSS class string appended to top-level skeleton overlay container.
ignoreHidden boolean true When true, elements with display: none or visibility: hidden are ignored.

SkeletonController Interface

createSkeleton() returns a controller object to manage teardown and state:

Method / Property Type Description
restore() () => void Fades out skeleton overlay over fadeDuration and restores original element visibility.
skeletonElement HTMLElement Direct DOM reference to generated .fluentez-skeleton-overlay element.
targetElement HTMLElement Direct DOM reference to target container element.
isDestroyed boolean Read-only boolean property indicating whether skeleton has already been restored.

Vanilla JavaScript Examples

1. Basic Setup & Restoration

import { createSkeleton } from '@fluentez/ui';

const userCard = document.querySelector('#user-card');

// 1. Create skeleton loader matching userCard UI
const skeleton = createSkeleton(userCard, {
  animation: 'shimmer',
  theme: 'auto',
  borderRadius: 'auto',
});

// 2. Fetch data asynchronously and restore original UI
fetchUserProfile().then((data) => {
  renderUserProfile(data);
  skeleton.restore();
});

2. Custom Color Palette & Animation

const skeleton = createSkeleton('#product-card', {
  animation: 'wave',
  theme: {
    background: '#1e1e2e',
    skeleton: '#313244',
    highlight: 'rgba(255, 255, 255, 0.12)',
  },
  borderRadius: 12,
  fadeDuration: 300,
});

3. Excluding & Keeping Elements

const skeleton = createSkeleton('#feed-item', {
  // Skip skeletonizing action buttons
  exclude: '.action-btn, button',
  // Keep brand icon visible as-is inside loading overlay
  keep: '.brand-logo',
});

React API & Examples

Option 1: SkeletonContainer Component

import { SkeletonContainer } from '@fluentez/ui/react';

export function UserProfileCard({ isLoading, user }: { isLoading: boolean; user?: User }) {
  return (
    <SkeletonContainer
      loading={isLoading}
      options={{
        animation: 'shimmer',
        theme: 'auto',
        borderRadius: 'auto',
      }}
    >
      <div className="profile-card">
        <img src={user?.avatar} alt={user?.name} className="avatar" />
        <h3>{user?.name}</h3>
        <p>{user?.bio}</p>
      </div>
    </SkeletonContainer>
  );
}

Option 2: useSkeleton Hook

import React from 'react';
import { useSkeleton } from '@fluentez/ui/react';

export function ArticleFeed({ isLoading }: { isLoading: boolean }) {
  const containerRef = useSkeleton<HTMLDivElement>(isLoading, {
    animation: 'pulse',
    fadeDuration: 200,
  });

  return (
    <div ref={containerRef} className="feed-list">
      <article className="feed-item">
        <h2>Article Title Placeholder</h2>
        <p>Article body content paragraph placeholder text.</p>
      </article>
    </div>
  );
}

HTML Data Attributes Control

Control skeleton generation directly within HTML markup without writing JavaScript options:

Attribute Target Element Effect
data-skeleton-ignore Any HTML element Skips skeleton creation for this element and all its children. Element remains untouched.
data-skeleton-keep Any HTML element Keeps element visible as-is inside the skeleton overlay (useful for brand logos or static icons). 
<div id="card">
  <h2>User Profile Title</h2>
  
  <!-- Icon remains visible untouched during loading -->
  <svg data-skeleton-keep className="logo-icon">...</svg>
  
  <!-- Action button is ignored completely -->
  <button data-skeleton-ignore>Action</button>
</div>
