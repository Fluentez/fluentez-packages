Hook 03

useAvailableHeight

Dynamically computes the available vertical height for a container element by measuring its parent client height minus its previous sibling height in O(1).

⚡

Zero-flicker calculation using useLayoutEffect and ResizeObserver before browser paint. No hardcoded pixels or REMs required.

Function Signature

function useAvailableHeight<T extends HTMLElement = HTMLDivElement>(
  fallbackHeight?: string
): {
  ref: RefObject<T | null>;
  height: string;
};

Parameters

Parameter Type Required Default Description
fallbackHeight string No '100%' Initial fallback CSS height string applied before DOM measurement completes.

Return Values

Property Type Description
ref RefObject<T | null> React ref attached to the container element to be height-adjusted.
height string Computed CSS pixel height string (e.g., '782px') dynamically calculated from DOM dimensions.

Production Usage Example: Dynamic Messenger Layout

import React from 'react';
import { useAvailableHeight } from '@fluentez/hooks/use-available-height';

export function MessengerView() {
  // Dynamically calculate available space below header/navbar without hardcoding pixels
  const { ref, height } = useAvailableHeight<HTMLDivElement>();

  return (
    <div className="app-layout" style={{ height: '100vh', display: 'flex', flexDirection: 'column' }}>
      <header style={{ height: '60px', background: '#1e293b', color: '#fff' }}>
        Navbar Navigation
      </header>
      <main ref={ref} style={{ height, display: 'flex', overflow: 'hidden' }}>
        <aside style={{ width: '280px', borderRight: '1px solid #cbd5e1' }}>
          Sidebar Conversations
        </aside>
        <section style={{ flex: 1, overflowY: 'auto' }}>
          Active Chat Stream Content
        </section>
      </main>
    </div>
  );
}
