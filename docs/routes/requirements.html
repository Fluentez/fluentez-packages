Package Version Notes
react ≥ 16.8.0 Required for React Hooks and Skeleton component bindings.
react-dom ≥ 16.8.0 Required for DOM layout rendering.
react-router-dom ≥ 6.0.0 Optional peer dependency (only required for useScrollRestoration).
