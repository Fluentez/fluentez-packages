Hook 01

useInfiniteScrollTop

Prevents reverse scroll position jumps when prepending historical data batches to reverse timelines like chat applications and log feeds.

✦

Automatically calculates vertical layout offsets via requestAnimationFrame to keep user scroll focus locked smoothly on active items.

Function Signature

function useInfiniteScrollTop<T>(
  containerRef: RefObject<HTMLElement | null>,
  totalPages: number,
  page: number,
  setPage: Dispatch<SetStateAction<number>>,
  newData: T[],
  shouldReverse?: boolean
): { data: T[]; setData: Dispatch<SetStateAction<T[]>> }

Parameters

ParameterTypeDescription
containerRefRefObject<HTMLElement>Ref attached to the scrollable overflow container element.
totalPagesnumberTotal available page count from backend API.
page / setPagestateCurrent active page index and React state setter.
newDataT[]Newly fetched items array. Deduplicated by _id or id.
shouldReversebooleanOptional. Reverses each incoming batch array. Default false.

Example Usage

const { data: messages } = useInfiniteScrollTop(
  containerRef, totalPages, page, setPage, fetchedMessages, true
);

return (
  <div ref={containerRef} style={{ overflowY: 'auto' }}>
    {messages.map((msg) => <Message key={msg._id} {...msg} />)}
  </div>
);

Hook 02

useScrollRestoration

Persists and restores scroll coordinates on overflow HTML elements across client-side router navigation events (POP vs PUSH).

↗

Works seamlessly with react-router-dom. Automatically handles session storage persistence.

Function Signature

function useScrollRestoration<T extends HTMLElement = HTMLDivElement>(
  key: string,
  isReady: boolean = true
): { containerRef: RefObject<T | null>; handleScroll: () => void }

Parameters

ParameterTypeDescription
keystringUnique key identifier for persisting scroll coordinates in sessionStorage.
isReadybooleanSet false until dynamic content finishes rendering. Default true.

Example Usage

const { containerRef, handleScroll } = useScrollRestoration(
  'article-feed-scroll',
  articles.length > 0
);

return (
  <main ref={containerRef} onScroll={handleScroll} style={{ overflowY: 'auto' }}>
    {articles.map((article) => <ArticleCard key={article.id} {...article} />)}
  </main>
);

Hook 03

useAvailableHeight

Dynamically computes the available vertical height for a container element by measuring its parent client height minus its previous sibling height in O(1).

⚡

Zero-flicker calculation using useLayoutEffect and ResizeObserver before browser paint. No hardcoded pixels or REMs required.

Function Signature

function useAvailableHeight<T extends HTMLElement = HTMLDivElement>(
  fallbackHeight: string = '100%'
): { ref: RefObject<T | null>; height: string }

Parameters

ParameterTypeDescription
fallbackHeightstringOptional initial fallback CSS height string before DOM measurement. Default '100%'.

Example Usage

import { useAvailableHeight } from '@fluentez/hooks/use-available-height';

export function MessengerView() {
  const { ref, height } = useAvailableHeight();

  return (
    <div className="app-layout" style={{ height: '100vh' }}>
      <header>Navbar Navigation</header>
      <main ref={ref} style={{ height, overflow: 'hidden' }}>
        <ChatContent />
      </main>
    </div>
  );
}

Architecture

Design Specifications

Engineered to stay out of your way and deliver zero-flicker UI interactions.

1. Layout Shift Prevention

Uses useLayoutEffect to perform all DOM measurements and scroll coordinate adjustments synchronously before browser screen paint.

2. Debounced Storage Operations

Scroll position writes to sessionStorage are debounced at 100ms to eliminate main thread blocking during active user scrolling.

3. O(1) ResizeObserver

useAvailableHeight observes element and parent layout shifts with ResizeObserver and requestAnimationFrame without thread polling or loops.
